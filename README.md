# Grid Landing Page

A responsive landing page built as part of a Frontend Mentor challenge. This project helped me practise CSS Grid, responsive layouts, and JavaScript interactions.

## ✨ Features

- Responsive page layout

- Interactive navigation menu
- Animated statistics counter
- Mobile-friendly design
- Accessibility considerations

## 📚 What I Learned

While building this project, I practised:

- Creating responsive layouts using CSS Grid and media queries.
- Implementing a mobile navigation menu with JavaScript.
- Using `classList.toggle()` to control menu visibility.
- Updating accessibility attributes such as `aria-expanded` and `aria-label`.
- Creating animated number counters using `setInterval()`.
- Exploring `window.matchMedia()` to check media queries in JavaScript.
- Respecting reduced-motion preferences for a more accessible experience.
